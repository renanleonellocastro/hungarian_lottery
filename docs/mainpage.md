# Hungarian Lottery API Reference {#mainpage}

C++17 engine for the Hungarian lottery model (Otoslotto): every player picks
5 distinct numbers from 1 to 90, and after each draw of 5 numbers the engine
reports how many players matched 2, 3, 4 and 5 numbers.

This site is generated by CI from the `main` branch.

## Where to start

* hungarian::ILotteryProcessor is the strategy interface: `preComputeWinners()` once, then `computeWinners()` per draw.
* hungarian::BruteForceLotteryProcessor scans every ticket for every draw, O(N) per draw. It is the reference implementation.
* hungarian::CachedLotteryProcessor counts every 2, 3, 4 and 5 number subset of every ticket once, then answers a draw with
  26 hash lookups and an inclusion exclusion correction, independent of the number of players.
* hungarian::Lottery wires the file reader, the selected strategy and the console together.
